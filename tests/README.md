# اختبارات تبارك جيم

```
npm install
npm test                 # كل المجموعات
node tests/run.js المال  # مجموعة واحدة (بحث بجزء من الاسم)
TG_JSON=out.json npm test  # حفظ النتائج بصيغة JSON
```

الاختبارات تفتح الملف في متصفح حقيقي (Chromium عبر Playwright) وتعمل فوق
`window.TG` وحده — لا فوق تفاصيل الواجهة. لكل مجموعة سياق تخزين نظيف، فلا
تتسرّب بيانات مجموعة إلى أخرى.

المسار التنفيذي للمتصفح يُقرأ من `TG_CHROME` إن اختلف عن الافتراضي
(`/opt/pw-browsers/chromium-1194/chrome-linux/chrome`).

## المجموعات

| المجموعة | ما تثبته |
|---|---|
| ثوابت المال | كل دفعة تُنشئ سطر إيراد واحداً، المقبوض ≤ المستحق، الطباعة لا تصنع مالاً، حذف الدفعة يُبطل وصلها، المتوقّع في الدرج = الافتتاحي + الداخل − الخارج، والمصروف غير النقدي لا يُخصم منه |
| ثوابت المخزون | الرصيد = مجموع الحركات، لا رصيد سالب، وإلغاء الفاتورة يعيد الكمية |
| ثوابت الاشتراك | النهاية = النهاية الأصلية + أيام الأحداث، بعد الإنشاء والتجميد والتمديد والتعديل وإلغاء الحدث |
| الترقية v3/v4/v5 ⇐ v6 | الترقية على نسخة مستعادة من إصدار أقدم لا تغيّر مبلغاً ولا تحرّك نهاية اشتراك، وتشغيلها مرتين يعطي النتيجة نفسها |
| نموذج الحصص | القالب يولّد مواعيد، والحضور يحمل معرّف الموعد ويُعلّم الحجز، ولا التحاق ثابت بقي |
| العملة والجداول | العملة تُقفل بعد أول حركة مالية، وتغيير تسمية طريقة الدفع لا يمسّ سجلاً |
| البيانات التجريبية | تُحمَّل وتُحذف بالكامل من كل الجداول |
| الاستمرارية | الكتابة تنجو من إعادة التحميل (ومعها الملاحظات والتوزيعات والفترات المقفلة والشاشة الافتتاحية)، والنظام يقلع على التخزين المحلي ثم على الذاكرة مع تحذيرها |
| النماذج والشاشات المنبثقة | نماذج الاشتراك والمصروف والقبض وسجل الدفعات وشاشة الفاتورة |
| رسم كل الشاشات | كل شاشة وكل تبويب مالي وكل قسم إعدادات يُرسم بلا خطأ في الـ console |
| مسار الاستقبال الكامل | مشتركة ⇐ اشتراك بدفعة جزئية ⇐ وصل ⇐ قبض الباقي ⇐ إعادة طباعة ⇐ تجميد ⇐ حضور ⇐ بيع ⇐ إقفال الصندوق |
| حفظ وطباعة وصل | الطباعة لا تصنع مالاً، ومنع نافذتها لا يُفقد الدفعة ولا يُنشئ دفعة ثانية، وإعادة المحاولة تعطي الوصل نفسه |
| الاستقبال السريع | الكود + Enter (بالحرف وبالأرقام وبالأرقام العربية)، إنهاء التجميد اليوم واحتساب ما مضى وحده، وافتراضات التجديد وعدم مساس السجل القديم |
| ملاحظات الفريق | الحفظ بالكاتبة والتاريخ، رفض الفارغة وبلا مشتركة، التثبيت والتعديل والحذف |
| الفترات وتوزيعات الشركاء | لا توزيع قبل الإقفال، الربح يُثبَّت بالإقفال، التوزيع يقلّل السيولة ولا يقلّل الربح ولا يظهر مصروفاً، وكشف الشريكة |
| الحصص المشمولة | المنح مع الاشتراك، الاستهلاك، إسقاطها بأرشفته كحدث ظاهر، وإعادتها بالاسترجاع |
| البحث العام | ثلاث نتائج للمجموعة، المشتركات أولاً، القفز بالكود ورقم الوصل، أفعال الصف، والتطبيع العربي |
| الشاشة الافتتاحية | الافتراضي والحفظ |
| المسار الحرج الكامل للمرحلة الأولى | الواحدة والثلاثون خطوة كاملة من إنشاء المشتركة إلى طباعة كشف الشريكة |
| النسخ الاحتياطي والاستعادة | كل الجداول في النسخة، الاستعادة تُرجع الملاحظات والفترات المقفلة، وإعادة التهيئة تفرّغ الجديد أيضاً |
| التقارير والتصديرات | بناء التقرير، فصل القيمة عن المقبوض، ومطابقته لسطور الإيراد |
