# اختبارات تبارك جيم

```
npm install
npm test                 # كل المجموعات
node tests/run.js المال  # مجموعة واحدة (بحث بجزء من الاسم)
TG_JSON=out.json npm test  # حفظ النتائج بصيغة JSON
npm run test:paths       # قواعد طرف الصدأ الخالصة: المسارات وحدّ نافذة البدء (على أي نظام)
npm run test:docx        # ملفات Word يفتحها LibreOffice Writer ويُخرجها PDF (يتخطّى إن لم يوجد)
node scripts/verify-build.mjs        # بوّابات البناء (المصدر + الواجهة المولَّدة)
```

الاختبارات تفتح الملف في متصفح حقيقي (Chromium عبر Playwright) وتعمل فوق
`window.TG` وحده — لا فوق تفاصيل الواجهة. لكل مجموعة سياق تخزين نظيف، فلا
تتسرّب بيانات مجموعة إلى أخرى.

المسار التنفيذي للمتصفح يُقرأ من `TG_CHROME` إن اختلف عن الافتراضي
(`/opt/pw-browsers/chromium-1194/chrome-linux/chrome`). وإن لم يوجد أيٌّ
منهما استُعمل متصفّح Playwright نفسه، فتعمل المجموعة على أي جهاز بلا ضبط.

| الطباعة — لا معاينة متصفّح في تطبيق ويندوز | Ctrl+P لا يصل إلى محرّك العرض بل إلى حوار النظام — **على تخطيط لاتينيّ وعلى تخطيط عربيّ (`key:'ح'` مع `code:'KeyP'`) وبضغطة مفاتيح حقيقية لا حدثٍ مُركَّب**؛ وشاشةٌ بلا مستند تُجيب بالعربية؛ ودورة كاملة: طباعة، إلغاء، إعادة، فشل، تعافٍ — والعدّاد يعدّ الحوارات التي فُتحت فعلاً ولا يعدّ الفاشلة |
| المتصفح — لم يتغيّر شيء | لا جسر ولا مدخل لمركز الملفات، وCtrl+P لا يُعترض، والتصدير تنزيل، والطباعة في وعاء مستقلّ |
| البناء — هويّة يُفرَّق بها بين نسختين | معرّف البناء يُقرأ من الجسر ويُعرض تحت الإصدار، ولا بصمة ولا تاريخ يُخترعان في الواجهة، والمتصفح بلا هويّة ولا بديل؛ والنسخة متّفقة في المواضع الأربعة، والبصمة تُخبز وقت الترجمة، وسياسة نهايات الأسطر مكتوبة |
| خطّ البناء — بوّابات قبل المثبّت | الذاكرة المؤقّتة لا تحمل ناتج بناء، والبوّابات الأربع بترتيبها وكلّها قبل الرفع، والمثبّت يُثبَّت فعلاً ويُفحص ما ثُبّت، واسم الحزمة يحمل التشغيل والبصمة، ومثبّت واحد لا اثنان |
| سطح المكتب — الإقلاع والتخزين | الإقلاع خلف سياسة أمن المحتوى، والتخزين IndexedDB لا بديلاً احتياطياً، وأربعون جدولاً، ومخطّط 8، وكتابة وقراءة حقيقيتان، **ولا طلب شبكة خارجيّ واحد** |
| سطح المكتب — الطباعة | ستّة مستندات و`window.open` معطّلة: وعاء يُفتح، ومستند غير فارغ، و`print()` **مرة واحدة**، واتجاه RTL، وأنماط النظام، وقواعد `@page` — والوعاء مرسوم لا مخفيّ، وخارج الشاشة، ولا يتكدّس |
| سطح المكتب — النسخ الاحتياطي والهجرة | نادٍ كامل ⇐ نسخة ⇐ استعادة في سياق تخزين **نظيف**: الإجماليات الستّة وعدد سجلات الأربعين والسيولة والمستحقات كما كانت، والشعار المتحرّك عاد بإطاره، والمالكة والاستقبال دخلتا بكلمتَي المرور نفسيهما |
| سطح المكتب — الهوية المتحرّكة | الأوضاع الثلاثة × (تقليل الحركة مفعَّل/مطفأ) على وقت تشغيل سطح المكتب، والطباعة ثابتة في كل حال، والبقاء بعد إعادة التشغيل وعبر الاستعادة |
| سطح المكتب — الدخول والصلاحيات | تهيئة أول حساب ورمز الاسترجاع، والتلبيد لا النصّ، ورمز ردٍّ واحد لا يكشف وجود الحساب، ودور الاستقبال المحدود عند حدّ الفعل، والتعطيل، والاسترجاع، وإعادة التحميل لا تُخرج المستخدمة |
| سطح المكتب — بلا شبكة | كل طلب خارج المستند مقطوع، ثم يوم عمل كامل: مشتركة واشتراك ودفعة وحضور ومصروف ومخزون وبيع وتقرير ونسخة واستعادة وطباعة وتصدير — **وصفر طلب خارجيّ** |
| سطح المكتب — العربية والمسارات | أسماء عربية وبحث عربيّ، وأسماء ملفات التصدير عربية بلا فاصل مسار، واسم مستخدمة وكلمة مرور عربيّان، ولا اعتماد على مسار قرص أو مجلّد عمل |
| سطح المكتب — الأداء على قاعدة كبيرة | 132,235 سجلاً (10,000 مشتركة · 20,000 دفعة · 10,000 فاتورة · 22,000 حركة مخزون): أحد عشر قياساً **مقارَناً بالمتصفح** وبحدّ مطلق، والذاكرة |

## مجموعات سطح المكتب

تسع مجموعات في `tests/desktop.js` تفرض على متصفّح حقيقي **قيود وقت تشغيل
Tauri الثلاثة مجتمعة** بدل افتراض أنها لا تضرّ:

1. `window.open` تُرجع `null` — غلاف Tauri لا يسجّل معالج نوافذ جديدة، فيردّ
   wry الطلب بلا نافذة. كل ما بُني على نافذة منبثقة يسقط هناك صامتاً.
2. سياسة أمن المحتوى المكتوبة في `src-tauri/tauri.conf.json` تُرسَل ترويسةً
   فعلاً — تُقرأ من ملف التهيئة نفسه فلا يفترق الاختبار عمّا يُشحن.
3. الواجهة تُقدَّم من `app/` — مجلّد البناء الذي يشحنه المثبّت — لا من ملف
   الجذر.

وما **لا** تدّعيه: أنها WebView2. المحرّك هنا Chromium، وWebView2 مبنيّ
عليه أيضاً، لكنهما ليسا الشيء نفسه. ما لم يُقَس على ويندوز مكتوب في
`docs/QA-phase-4.md` §14 لا هنا.
